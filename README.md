# OPPO 耳机 Mac 控制器

一款 macOS 菜单栏耳机控制工具，用于在 Mac 上查看耳机电量、切换降噪模式，不必每次都打开手机上的耳机应用。

系统要求：macOS 26 或更高版本。

## 能做什么

- 显示左耳、右耳和充电盒电量。
- 显示耳机和充电盒的充电状态。
- 自动读取并显示 Air5 Pro 固件版本。
- 切换降噪、关闭降噪和通透模式。
- 在降噪模式下选择深度、中度、轻度或智能强度。
- 切换至臻原音、纯享人声和澎湃低音三种均衡器预设。
- 打开或关闭游戏低延迟模式。
- 可选低电量通知，在耳机电量不足时提醒。
- 连接、重新连接或意外断开时显示不抢焦点的状态浮窗。
- 可选在菜单栏显示真实左右耳和充电盒电量；无数据的充电盒不占用显示行。
- 默认在 Dock 中显示应用图标，也可以在详情设置中关闭。
- 连接或断开耳机。
- 可选开机自动启动。
- 同时配对多副兼容耳机时，可以在面板中选择要控制的设备。
- 与手机上的耳机设置保持同步：在任意一端切换模式，另一端会自动更新。

如果耳机没有提供左右耳的独立电量，应用会显示系统可取得的合并电量。充电盒合上后可能暂停上报电量，应用会保留本次使用期间最后一次获取到的充电盒电量。

## 已验证的 OPPO 耳机

- OPPO Enco Air5 Pro

其他 OPPO 耳机也可以尝试连接；不同型号支持的功能可能有所不同。

## 安装

[![前往下载](https://img.shields.io/badge/前往-GitHub%20Releases-blue?style=for-the-badge&logo=github)](https://github.com/Zeno-cc/OPPO-Earbuds-Mac-Controller/releases)

在 Releases 页面下载 `.dmg` 安装包。双击打开后，把应用图标拖到“应用程序”快捷方式即可完成安装。

如果 macOS 阻止打开，请在终端执行：

```bash
xattr -cr "/Applications/OPPO Earbuds Mac Controller.app"
```

## 怎么使用

1. 先在 Mac 的“系统设置 > 蓝牙”中配对耳机。
2. 启动应用，点击菜单栏中的耳机图标。
3. 如果耳机尚未连接，点击面板右上角的“连接”。
4. 在面板中查看电量，或切换降噪、均衡器和游戏模式。

不打开面板也能做三件事：菜单栏电量把左耳（L）和右耳（R）上下叠放以省出宽度，未读到的槽位显示 `—`；充电盒（C）只在读到自己的数据时才跟在下面那一行，读不到就整段隐藏。菜单栏不会用合并电量或系统兜底值推断某一只耳机的电量。`Option + 点击`菜单栏图标在降噪与通透之间切换；右键图标打开原生菜单，直接选择降噪、通透、关闭和降噪强度。切换结果会用一个短浮窗提示成功或失败，浮窗和连接状态浮窗共用同一个屏幕位置，不会同时出现。

点击右上角“更多”按钮，可以设置连接状态浮窗、菜单栏电量、快速控制快捷键、Dock 图标、开机自动启动和低电量通知，也可以查看设备信息或再次打开 v1.5 新功能介绍。快捷键在“更多 → 快速控制”里录入：点一下按钮，按下组合键即可，按 `Esc` 取消、按 `Delete` 清除。至少需要一个 Command、Option 或 Control 修饰键；注册失败时会保留原来的快捷键并给出提示。录入使用应用内的按键事件，不申请辅助功能权限。

首次启动时，请允许应用访问蓝牙。

## 开发验证

运行 `swift test` 执行回归测试，`bash build.sh debug` 构建本目录中的应用，`bash scripts/verify-app-bundle.sh` 检查可执行文件、版本、macOS 要求、图标资源和签名。构建与验证不会自动启动或安装应用。

高级控制功能的证据边界与手机侧采集要求见 [Air5 Pro 协议证据](docs/AIR5_PROTOCOL_EVIDENCE.md)。耳机的双设备自动连接由耳机/官方手机体验负责，本应用不提供优先设备或手动切源控制；本应用提供盒内/盒外位置状态，但不提供入耳检测。自定义 EQ 已完成协议、耳机端管理以及 Mac 本地方案保存/离线载入的实机验收，跨端冲突与失败场景仍需单独补充证据。Alive Audio 已取消，不属于开发范围。

「音效 → 自定义均衡器」支持多曲线列表、新增、命名编辑、10 段调节、直接启用及删除；用户已于 2026-09-07 确认管理流程实机验证成功。编辑器采用左侧曲线列表、横向十段推子及固定底部操作区：拖动推子或使用方向键按 1 dB 调节，点击增益数值单段归零，「全部归零」只修改草稿。编辑后点击「保存并启用」（⌘S），名称修改也在此时写入；新增由耳机分配 ID，删除需在窗口内确认。所有操作均查询耳机列表核对结果，读取冲突时保留草稿供核对。v1.5.0 已发布；本地方案保存、断开入口和重新载入已于 2026-09-10 完成实机验收，手机参与的跨端冲突与失败矩阵不在本次发布中宣称。

编辑器另有「Mac 本地方案」：点击「保存到 Mac」持久保存当前曲线，点击本地方案仅载入草稿；随后明确点击「新增并启用」才会发送到耳机并核对读回。删除本地方案不删除耳机曲线。耳机断开时，可从主面板「Mac 本地 EQ 方案」入口离线新建、编辑和保存；本地保存、载入、删除均不发送蓝牙设置命令。2026-09-10 已完成本地保存、断开入口和载入流程的真机 UI 验收。
