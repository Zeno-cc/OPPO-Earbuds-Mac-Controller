## 其他 OPO 耳机

应用会发现提供相同 `oppointeraction` 服务的已配对耳机，但不会根据品牌猜测协议值。

- 未识别型号可以读取通用的电量和佩戴报告。
- 未识别型号保持只读，不发送降噪命令。
- 新型号只有在取得并验证真实设备数据后才会加入适配列表。

macOS 的蓝牙接口有时只提供一个合并电量。此时界面会明确显示合并值，不会将它伪装成左右耳独立电量。
