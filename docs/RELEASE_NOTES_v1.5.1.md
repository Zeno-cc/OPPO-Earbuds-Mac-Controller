# OPPO Earbuds Mac Controller v1.5.1

## 这次更新

- 加入 OPPO Enco Free4 支持：已验证关闭、通透以及深度、中度、轻度、智能降噪状态；自适应模式可识别，但不提供主动切换。
- 加入基于 Sparkle 的应用内更新。更新入口收为“关于”里的小图标：点击检查，发现新版本后图标变蓝，再点击打开下载与安装窗口；稍后安装仍可重新打开。
- 更新包和更新源使用 Sparkle EdDSA 签名验证；自动检查更新不等于自动安装。

## 升级方式与限制

- v1.5.0 尚无更新器，因此首次升级到 v1.5.1 需要从 GitHub Release 下载 DMG，手动拖入“应用程序”。此后才能使用应用内更新。
- 最低系统仍为 macOS 26。分发包沿用 ad-hoc 签名；更新后 macOS 可能再次请求蓝牙权限，允许后控制功能才会恢复。
- 本版本不新增 Widget、Alive Audio、入耳检测或双设备手动切源控制。
