# OPPO Earbuds Mac Controller v1.4.0

## 这次更新

- 新增自定义 EQ 管理：创建、命名、编辑、启用和删除耳机端曲线。
- 新增完整曲线读回确认；草稿与耳机当前状态分离，外部变化不会静默覆盖编辑内容。
- 新增 Mac 本地 EQ 方案：可在本机保存、载入和删除曲线，断开耳机时也能离线编辑。
- 本地方案的保存、载入和删除不会发送蓝牙设置命令；只有“新增并启用”或“保存并启用”才会写入耳机。
- 显示已验证的盒内/盒外位置状态，不把盒外状态推断为已佩戴。
- 更新 v1.4 首次启动说明，保留原生、克制的连接反馈和 Liquid Glass 界面体验。

## 范围说明

- 最低系统要求保持为 macOS 26 或更高版本。
- 双设备自动连接仍由耳机和官方手机体验负责，Mac 不提供优先设备或手动切换音源控制。
- 不包含 Widget、Alive Audio、独立入耳检测、BLE/OTA 或付费签名能力。
- 继续保留 realme Buds T500 Pro 的既有兼容性测试；本版本没有新增 T500 功能承诺。

## 验证

- `swift test`：141 个测试通过。
- `swift test -c release`：141 个测试通过。
- `bash build.sh release` 与 `bash scripts/verify-app-bundle.sh`：通过。
- 发布包使用项目现有的 ad-hoc 签名；首次打开若被 macOS 拦截，请按 README 中的 `xattr` 命令处理。

## 证据边界

软件回归和 Mac 本地方案 UI 已通过验证。手机参与的跨端冲突/失败矩阵需要 Android 端 HCI 日志与现场操作，本包不把这部分未取得的物理证据宣称为已完成能力。
