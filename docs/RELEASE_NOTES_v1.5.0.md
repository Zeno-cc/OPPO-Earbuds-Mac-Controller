# OPPO Earbuds Mac Controller v1.5.0

## 这次更新

- 菜单栏电量改为左耳（L）和右耳（R）上下排列，减少菜单栏宽度占用。
- 充电盒（C）只有在读到自己的有效电量时才显示；没有数据时自动隐藏，不再显示无意义的占位内容。
- 菜单栏电量使用独立的两行原生绘制，解决多行标题被状态栏裁剪和垂直偏移的问题。
- 增加 `Option + 点击` 在 ANC 与通透之间快速切换。
- 增加右键原生菜单，可直接选择降噪、关闭、通透和降噪强度。
- 增加可选全局快捷键，支持录入、清除、替换失败恢复和持久化，不需要辅助功能权限。
- 增加 Quick Action HUD，并与连接状态浮窗共享显示位置，避免浮窗重叠。
- 更新快速控制设置、v1.5 新功能说明和使用文档。

## 范围说明

- 最低系统要求保持为 macOS 26 或更高版本。
- 双设备自动连接仍由耳机和官方手机体验负责，Mac 不提供优先设备或手动切换音源控制。
- 不包含 Widget、Alive Audio、独立入耳检测、Head Tracking、BLE/OTA、自动音频接管或 macOS 26 以下兼容。
- 发布包继续使用项目现有的 ad-hoc 签名；首次打开若被 macOS 拦截，请按 README 中的 `xattr` 命令处理。
