# OPPO Earbuds Mac Controller v1.6.0

## 这次更新

- 改进操作反馈：等待提示持续到实际结果，成功和失败分别收尾，重复快捷操作不会吞掉原有回执。
- 改进连接浮窗：连续事件原位衔接、悬停可继续阅读，过时提示及时撤下，退出中重入不再被旧回调隐藏。
- 主面板的选中、等待和按下反馈更集中，减少无关布局动画，EQ 和游戏模式等待时保持原有位置。
- 自定义 EQ 增加原生触控板刻度反馈：拖动跨过 1 dB 时轻触一下，归零使用不同触感，快速拖动不补播震动。
- 设备信息刷新现在显示真实完成或失败，保留已有型号和固件信息；首次新功能介绍保持焦点，减少动态效果设置下移除自定义空间运动。

## 升级方式与限制

- v1.5.1 及以后版本可在“更多 → 关于”检查并确认安装更新；v1.5.0 及更早版本需手动安装 DMG。
- 最低系统仍为 macOS 26，更新包和更新源继续使用原有 Sparkle 签名身份；应用采用 ad-hoc 签名，更新后可能再次请求蓝牙权限。
- 触觉反馈取决于输入设备及系统设置，不支持的设备保留原来的调节方式；本版本不增加压力控制、Widget、Alive Audio、入耳检测或手动切源。
